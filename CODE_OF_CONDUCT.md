# Code of conduct

## The short version

Be civil. Argue about the code, not the person. Assume competence.

## Expected

- Criticism aimed at the work: a diff, a design, a claim.
- Reproductions with a seed, a browser and a version.
- Patience with people whose first language is not English.

## Not tolerated

- Harassment, insults, slurs, or sustained bad faith.
- Sexual attention or imagery directed at anyone.
- Publishing someone's private information.
- Dismissing a report of the above.

## Enforcement

Report to sohilmomin2000@gmail.com. Maintainer decides: edit or delete the content, warn, or block.
Decisions are final for this repository.

Applies to issues, pull requests, discussions, commit messages and any space where the project is
represented.
